# Unityの容量整理ツール(UnityProjectCleaner)
Unityプロジェクトの不要なファイルやフォルダ（`Library`, `Temp`, `Logs`, `obj`, `.vs` など）をドラッグ＆ドロップで一括削除し、ストレージ容量を大幅に軽量化するWindows用デスクトップツールです。

## ✨ 主な機能と特徴
先述の「構造・仕組み・堅牢性・機能」を意識して設計しています。

- **直感的なUI操作 (機能)**
  - ドラッグ＆ドロップによるフォルダ読み込み。
  - クリックによる削除対象の個別ON/OFF切り替え。
  - 常時表示のステータスバーによる進捗と残り時間の可視化。
- **フリーズ対策 (仕組み)**
  - 1フレームあたり最大50個ずつの分割削除処理を実装。
  - 削除処理とUI描画を並行させ、ツールが応答なしになるのを防いでいます。
- **安全な削除ロジック (堅牢性)**
  - 取得したファイルパスを「長い（深い階層）順」にソートしてから削除を実行し、親フォルダの削除エラーを防止。
  - `std::error_code` を用い、Officeファイルなどで使用中（ロック状態）のファイルは強制終了せずにスキップし、自動生成される `ErrorLog.txt` に記録します。
- **ステートマシン制御 (構造)**
  - 画面の状態を `enum class AppState` と `switch` 文で管理し、安全な画面遷移を実現しています。

## 🚀 使い方
1. 本ツール（`.exe`）を起動します。
2. 対象となるUnityのプロジェクトフォルダを、画面内にドラッグ＆ドロップします。
3. 削除対象のリストが表示されるので、確認して「削除開始」ボタンをクリックします。
4. 処理が完了したら、【R】キーで連続して別のプロジェクトを掃除するか、【ESC】キーでツールを終了します。
